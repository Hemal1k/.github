# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and keep the discussion about the work. Harassment, insults and
personal attacks are not accepted; such comments are removed and repeated behaviour leads to a block.

Problems can be reported privately through the Security tab of any HeMi project (Report a vulnerability) or by a
private message on GitHub to [@Hemal1k](https://github.com/Hemal1k).
