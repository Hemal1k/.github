# Contributing

Thank you for helping! These are small one-person projects, so a few simple rules:

- **Bugs and ideas**: open an issue with the form of the project (version and Windows version help a lot).
- **Pull requests**: welcome for fixes. For a bigger change or a new feature please open an issue first, so that the work
  is not wasted – the apps are kept deliberately simple.
- **Style**: follow the code around you. Texts are in English (US), most apps with a Czech translation (`tr("…", "…")` in
  the Rust apps, `L.T("…")` and `Loc.cs` in HeMiDock, `_locales` in HeMiTube); new options are off by default.
- **Building**: see the README of the project. Releases are built by GitHub Actions from the tagged source.
- By contributing you agree that your contribution is released under the MIT license of the project.
