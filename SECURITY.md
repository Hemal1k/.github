# Security policy

## Supported versions

Only the latest release of each project gets fixes – please update first: HeMi Launcher keeps all HeMi apps up to
date (HeMiDock and HeMiMizer can also update themselves), or download the latest release from the Releases page of
the project.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately on GitHub: the **Security** tab of the project →
**Report a vulnerability**. You get an answer within a few days; a fix is released as soon as possible and you are
credited in the release notes if you wish.

The downloads are built from the public source by GitHub Actions; checksums, the privacy policy and the code signing
policy are explained at https://hemal1k.github.io/about.html.
